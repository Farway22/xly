**不改动**：4.x.3 模型构建、4.x.4 模型求解与参数、全部公式与符号定义、全部图表的数据与编号、附件3 与附件4 的全量结果清单、各结论的方向。

## 一、总体规则

现有写法是"先把统计量摆完、最后一句说明"，读者要读完一整段才知道结论。目标写法是四拍：**先给结论 → 给 1～3 个支撑数字或指向表图 → 解释机制 → 回答建模问题**。

**规则 1（数字预算）**：每个自然段正文出现的指标数值（F1、MAE、相关系数、$p$、$\kappa$、百分比、秒）不超过 3 个；样本条数、维度、词元数、区间数等结构性计数不受此限，但同一句内不得连排 3 个以上。表里已有的数字，正文不再复述。

**规则 2（段落骨架）**：段首一句加粗结论，其后所有内容都服务于这一句，不出现"另外还有一组数据是……"的并列铺陈。

**规则 3（口径保留）**：评价协议、缺失定义、实验设置、比较口径必须原样保留（数字离开口径就无法核验），但集中成段，不散落在结果段里。

**规则 4（每个被删数字都要有归宿）**：数字离开正文后，必须能在某张表、某幅图或支撑材料文件中找到同值。找不到归宿的数字不删，作为该段唯一数字保留。

**预期效果**：正文压缩约 35%，浮动体数量与位置不变，净减 1～2 页；每节读完能记住 3～4 条结论而不是十几个指标。
